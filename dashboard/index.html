Token Radar

Protocols that record no token, ranked by what a token would be worth if their record held. One frozen DefiLlama snapshot, one model, every row with a farm plan.

Implied value = TVL × category multiple × growth × age × chains. Multiples are fitted on the snapshot's own token-trading protocols: ratios winsorized at the 95th percentile, then shrunk toward the global median. Costs in farm plans are planning ranges, never quotes. “No token recorded” means DefiLlama records no token for the protocol, never that it has none.
